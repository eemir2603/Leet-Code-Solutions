# 193. Valid Phone Numbers

**Platform:** LeetCode  
**Category:** Shell / Bash  
**Difficulty:** Easy  

##  Problem Overview

Given a text file `file.txt` containing a list of phone numbers (one per line), write a Bash script to print all valid phone numbers to `stdout`.

### Valid Formats:
1. `(xxx) xxx-xxxx` (e.g., `(123) 456-7890`)
2. `xxx-xxx-xxxx` (e.g., `123-456-7890`)

---

## Solution

Using `grep` with Extended Regular Expressions (ERE):

```bash
grep -E "^([0-9]{3}-|\([0-9]{3}\) )[0-9]{3}-[0-9]{4}$" file.txt
